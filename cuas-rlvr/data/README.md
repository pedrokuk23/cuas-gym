`gym` and `gym2` are relative links to the instances in `../cuas-gym/data/` (version 1 and version 2), so the
instances are stored once in the repository. Without symbolic links, pass `--data ../cuas-gym/data/gym2` to the scripts.

The SFT files in this folder were built from the reference solutions with `cuas_gym.sft_data`
(`CUAS_ANON=1` for the anonymized version).
